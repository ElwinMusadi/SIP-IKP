# Governance Approver Matrix

## 1. Governance Policy on Approval Authority

This document defines the formal mapping between blocking decisions and their designated organizational approval authorities for the **Sistem Informasi Pelaporan Insiden Keselamatan Pasien (IKP) IBS RSUD Prof. Dr. W. Z. Johannes Kupang**.
